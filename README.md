# BAROLOGY Quotation Management

Static browser-based quotation manager for GitHub Pages.

## Features
- Dashboard, All Quotations, Customers, and Quotation Settings
- Save and edit customer records
- Create, save, reopen, and delete quotations
- Select a saved customer on the quotation cover page
- Default VAT and discount settings

## Publish
Upload `index.html` and `README.md` to the root of a GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Data storage
This first version stores records in the browser's local storage on the device/browser used. Use browser export/backup regularly. Data is not automatically shared between different devices or browsers.
